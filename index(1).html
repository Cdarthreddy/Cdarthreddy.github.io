Projects

Latency reduction in the cloud

Main project · code on GitHub

A reinforcement-learning orchestrator that decides whether each task should run on an edge node or in the cloud, to cut latency in 5G-style environments. It uses Q-learning to learn the best route, with the infrastructure written in Terraform and the logic covered by 41 passing unit tests.

Incoming tasks Q-learning router Edge / EC2 nodes CloudWatch + S3

Serverless stock portfolio alerter

A fully serverless system that watches a list of stocks and sends an alert when a price moves past a set level. EventBridge runs it every 15 minutes during market hours, Lambda pulls prices, DynamoDB holds the watchlist, and SNS sends the alerts. I switched data sources mid-build when a broker API needed Indian residency, and tightened the IAM role to least privilege before going live.

EventBridge Lambda DynamoDB SNS alerts
Python · yfinance · IAM least privilege

Monitored web server on AWS

An Nginx web server on EC2 with an IAM role for S3 access, a CloudWatch alarm on CPU, and SNS email alerts. I proved the whole chain works by stress-testing the CPU and watching the alert arrive.

EC2 + Nginx CloudWatch alarm SNS email S3 via IAM role
